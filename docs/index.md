# Oficina de Sistemas Embarcados

Material da oficina oferecida na **Semana Universitária 2026**.

!!! info "Sobre a oficina"
    Uma introdução prática a sistemas embarcados: do acionamento de um LED
    à leitura de sensores e comunicação com a rede. Sem pré-requisitos além
    de lógica de programação básica.

## O que você vai construir

<div class="grid cards" markdown>

## Antes de começar

Traga um notebook com a IDE do Arduino (ou PlatformIO) já instalada. Os kits
com placas e sensores são emprestados durante a oficina.

| Item | Quantidade por equipe |
| --- | --- |
| Placa ESP32 DevKit v1 | 1 |
| Protoboard 830 pontos | 1 |
| Jumpers macho-macho | 20 |
| Cabo USB-A para micro-USB | 1 |
