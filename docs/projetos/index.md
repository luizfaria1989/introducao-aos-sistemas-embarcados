## Como cada projeto está organizado

Todo projeto segue a mesma estrutura de três páginas:

- **Visão geral** — o que o projeto faz e a lista de materiais.
- **Montagem** — o circuito, pino a pino.
- **Firmware** — o código comentado e como gravá-lo na placa.
